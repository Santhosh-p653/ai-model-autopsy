# AI Model Autopsy

Production-ready debugging framework combining **BentoML**, **Streamlit**, **MCP Servers**, **Groq**, and **Gemini Fallback**.

## Quickstart
1. Set environment variables:
   ```bash
   export GROQ_API_KEY="your-groq-key"
   export GEMINI_API_KEY="your-gemini-key"
   ```
